32. **#065 — Kanban edit/create modal is single-use after an Escape close.** Fixing #064 exposed a real regression-class bug: the global Escape handler dismisses a bespoke overlay by calling `m.remove()` directly, which cannot reach the owning module's close function. The sibling bespoke overlays (gm-create, dag-launch, a2a-*) were audited and use an idempotent `if (existing) { remove(); return; }` pattern with no stale flag, so they were unaffected. (kanban-modal-reopen 2 — source contract guard. Suite 262→264.)

33. **#066 — Docs quick-starts/features tabs crash on a null API response.** An automated click-fuzz across panes surfaced `TypeError: Cannot read properties of null (reading 'quick_starts')`. `docsTab('quickstarts')` did `fetch('…').then(r=>r.ok?r.json():null).catch(()=>({quick_starts:[]}))` — the `.catch()` only covers a network rejection, so a non-2xx response resolved `.then` to `null` and the very next line `d.quick_starts` threw, blanking the whole Docs tab on any server hiccup (same for the `features` tab's `d.features`). Both now coerce to `|| {}` before reading a property. The other `r.ok?r.json():null` sites were audited: those whose catch falls back to a plain object or guard with `if(!d) return;` are already safe. (docs-tab-null-deref 2. Suite 264→266.)

34. **#067 — Studio Monaco loader appended multiple times (breaks the editor).** `studioLoadMonaco()` only guarded on `window.monaco`/`studioMonacoLoaded`, both false while the loader is in flight, so every `initStudio()` before the load finished re-appended another `<script src=loader.js>`.

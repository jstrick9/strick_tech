⚙ Settings

Connect AI, customize appearance, manage agents, and configure backups.

Connect AI

The Settings pane opens to the Connect AI tab by default. Choose one of three paths:

  • 🖥️ Use AI on this Mac — Install Ollama for private local models. No account required.
  • ☁️ Connect cloud AI — Add an OpenRouter API key for 140+ models.
  • 🔌 Use another connection — For a compatible server you already use.

Theme & Aesthetics

Customize the look and feel:

  • Theme: Light, Dark, or Auto (follows system preference)
  • Accent Color: Choose your preferred accent color
  • Font Size: Small, Base, or Large
  • UI Mode: Simple (6 core features) or Power (all 69 features)

Navigation & Layout

Control how the sidebar and navigation work:

  • Sidebar width and collapse behavior
  • Default pane on startup
  • Keyboard shortcuts

AI Agents

Manage your AI agent fleet:

  • Create, edit, and delete custom agents
  • Set default models per agent
  • Configure system prompts

Local Ollama Server

Manage your local Ollama installation:

  • Check connection status
  • View installed models
  • Pull new models with one click

Storage & DB Backup

Manage your data:

  • Backup database (keeps last 10 backups automatically)
  • Export workspace as ZIP
  • Reset database (clears conversations, preserves vault keys)

⚡ One-Click Setup

Connect AI in 30 seconds. Auto-detects Ollama or configure OpenRouter.

FREE

How It Works

When you first open Agentic OS, a setup modal automatically detects available AI backends:

1

Ollama Detected (Recommended for Privacy)

If you have Ollama running, it's detected automatically. No API key needed. All data stays on your machine.

Install Ollama: curl -fsSL https://ollama.com/install.sh | sh then ollama pull llama3.2
2

OpenRouter Connected (140+ Models)

Paste your OpenRouter API key to access 140+ models including Claude, GPT-4o, Gemini, Llama, and more.

Get a free key at openrouter.ai/keys — many models are free with no credit card.
3

Neither Available

If no backend is detected, the modal guides you to install Ollama or add an API key.

Quick Setup API

Developers can trigger setup programmatically:

API Endpoint
POST /api/onboarding/quick-setup

// Response:
{
  "ok": true,
  "backends": [
    {"backend": "ollama", "status": "available", "models": 3},
    {"backend": "openrouter", "status": "no_key"}
  ],
  "recommended": {
    "backend": "ollama",
    "message": "Ollama detected with 3 model(s). Ready to use."
  }
}

💬 Chat with AI

Your first conversation in 60 seconds. 140+ models available.

FREE

Steps

1

Open Chat

Click Chat in the left sidebar (first item under Getting Started), or press ⌘/ from anywhere.

The chat pane opens with a welcome screen showing quick-start cards.
Chat Empty State
The chat empty state with quick-start cards, keyboard shortcuts, and the message input bar.
2

Connect AI

Choose your AI backend:

  • Ollama (free, local): Install from ollama.com — detected automatically
  • OpenRouter (cloud, 140+ models): Get a free key at openrouter.ai/keys
A one-click setup modal appears on first visit. It auto-detects available backends.
One-Click Setup Modal
The one-click setup modal detects Ollama automatically and offers OpenRouter API key input.
3

Pick a Model

Click the model dropdown in the chat header and choose from 140+ models:

  • Cloud AI: Claude 3.5 Sonnet, GPT-4o, Gemini 2.5 Pro, Llama 3.3 70B (free), Qwen3 235B (free)
  • Local (Ollama): Any model you've installed
  • Custom: Any OpenAI-compatible endpoint
Start with "Llama 3.3 70B" (free) or "Claude 3.5 Sonnet" (best quality).
4

Start Chatting!

Type anything and press Enter. Your AI responds in real-time with streaming.

  • Use the ⏹ button to stop generation
  • Messages are saved automatically
  • Attach files by dragging them into the chat
  • Use 🧠 Memory to ground responses in your knowledge base
Try: "Explain what FastAPI is in simple terms"

Pro Tips

/help — see all available commands
/swarm — run multiple agents on the same question
/code — ask AI to write code
Drag files into chat to add context
Press ⌘K to search everything

❓ Frequently Asked Questions

Answers to the most common questions about Agentic OS.

Setup & Configuration

Do I need an OpenRouter API key?

For cloud AI models, yes. Get a free key at openrouter.ai — many models are free with no credit card required. The key is stored encrypted on your machine. Alternatively, install Ollama for free local AI with no API key needed.

Is my data private?

Yes. Agentic OS is local-first. Your code, conversations, and documents stay on your machine. Only the text you send to AI models goes to the model provider — never to us.

Can I use this offline?

Basic features work offline (docs, kanban, saved conversations). AI features require internet to reach model providers. Ollama gives you fully offline local AI if installed.

How do I add my own AI models?

Go to Settings → API Keys. Add your OpenRouter key for 100+ models, or your Ollama URL for local models. You can also add direct Anthropic, OpenAI, or Google API keys.

How do I back up my data?

Go to Settings → click 'Backup Database'. This creates a timestamped .db file. You can also export your workspace as a ZIP from the Workspaces pane.

Features

What's the difference between Simple Mode and Power Mode?

Simple Mode shows only the 6 core features in a clean layout — perfect for getting started. Power Mode unlocks the full sidebar with all 69 panes. Switch anytime in Settings → Appearance.

Can multiple people use this?

The platform supports single-user operation. For team use, deploy with Docker and configure shared workspaces and role-based access in Settings.

What's a Steering File?

Steering files are persistent instructions that guide all your AI agents. Like giving every agent the same background context — your tech stack, coding standards, and project conventions. Go to AI Guidelines in the sidebar to set them up.

How do I check my license status?

Go to Settings → License to see your current tier and available features. All core features are available in the standard license.

Troubleshooting

AI is not responding

Check Settings → Connect AI to verify your connection. If using Ollama, make sure it's running (ollama serve). If using OpenRouter, verify your API key is valid.

Slow responses

Local models (Ollama) depend on your hardware. Cloud models depend on your internet connection. Try a smaller/faster model like Llama 3.2 3B or Gemini Flash.

How do I reset everything?

Settings → Storage & DB Backup → Reset Database. This clears all conversations and settings. Your API keys in the vault are preserved.
